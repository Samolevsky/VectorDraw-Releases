# VectorDraw — Downloads

VectorDraw is a vector graphics editor for the web and desktop.

- **Use it in the browser:** https://vectordraw.samolevsky.com
- **Download the desktop app:** [latest release](https://github.com/Samolevsky/VectorDraw-Releases/releases/latest)

| Platform | File |
| --- | --- |
| macOS — Apple Silicon (M1 and later) | `VectorDraw-<version>-mac-arm64.dmg` |
| macOS — Intel | `VectorDraw-<version>-mac-intel.dmg` |
| Windows 10/11 (64-bit) | `VectorDraw-<version>-win-x64.exe` |

Already installed? Use **VectorDraw › Check for Updates…** (macOS) or **Help › Check for Updates…** (Windows) to update in place.

Release notes for every version are on the [Releases](https://github.com/Samolevsky/VectorDraw-Releases/releases) page.

This repository only hosts installers and release notes; VectorDraw's source code is not public.
